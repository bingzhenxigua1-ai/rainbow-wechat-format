# hnust-wechat-cover

> 湖南科技大学微信公众号封面生成器。

按湖南科技大学官方微信公众号的年轻化、校园化视觉风格生成封面图。支持公众号首图（900×383）、小封面（383×383）以及兼顾大小封面（1283×383）三种常用尺寸。

## 支持尺寸

| 图片类型 | 尺寸 | 使用场景 |
|----------|------|----------|
| 公众号首图 / 大封面 | 900 × 383 | 单篇文章首图 |
| 公众号小封面 | 383 × 383 | 小图展示区的方形裁切区 |
| 兼顾大小封面 | 1283 × 383 | 同时满足大封面与小封面展示 |
| 公众号次图 | 200 × 200 | 多图文次条封面 |

## 五种风格

| 风格 | 适用主题 |
|------|----------|
| 活泼拼贴风 | 开学、社团、美食、轻松话题 |
| 手绘插画风 | 迎新、交友、心理、校园活动 |
| 实景新闻风 | 通知、权威发布、招生、重要新闻 |
| 清新扁平插画风 | 校园风光、节气、招生宣传 |
| 城市旅行拼贴风 | 假期、旅行、返乡、城市主题 |

详细视觉规范见 [`references/style-guide.md`](references/style-guide.md)。
